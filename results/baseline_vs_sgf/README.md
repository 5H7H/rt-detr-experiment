# 基线与 SGF 结果

- [epochs.csv](epochs.csv)：两组各 72 轮的 AP（%）和训练 loss，可用 Excel 打开。
- 两个 `.jsonl`：来自服务器的原始逐轮日志，每行对应一个完整 epoch，原始 AP 范围 0–1。
- [实验设置](../../docs/experiments.md)及[分析脚本](../../docs/analysis.md)。

最后一轮 SGF 相比基线：AP +0.103、AP50 +0.377、AP75 +0.092、AP small +0.146、AP medium -0.087、AP large +1.376 个百分点。差值从未四舍五入的原始值计算。单种子结果，不代表统计显著提升。

2026-09-26 的只读诊断：EMA lambda=0.491618；前 16 张验证图像门控均值 0.463950，注入范数比约 0.204112。小于 0.1 / 大于 0.9 的门控位置比例约 0.077646 / 0.054736。诊断说明分支在工作，但不能证明其选择了小目标；可用 inspect_sgf_gate.py 复查。

`source_sha256.json` 记录导出时服务器源代码文件的原始字节哈希。Git 的换行转换可能改变本地字节哈希；该文件用于记录历史导出来源，不是跨平台安装校验器。
